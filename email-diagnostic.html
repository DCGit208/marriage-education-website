🔧 Common Issues & Solutions

Issue 1: PHP mail() Function Disabled

Symptom: Form submits but mail() returns false

Solution:

  1. Contact iPage support to verify PHP mail() is enabled
  2. Check if SMTP is required instead of mail()
  3. Verify server-side mail configuration

Issue 2: Sender Email Not Configured

Symptom: Emails sent but never arrive

Solution:

  1. Log into iPage cPanel
  2. Go to Email Accounts
  3. Create/verify email: noreply@marriageducation.com
  4. Create/verify email: ambassadors@marriageducation.com

Issue 3: Emails Going to Spam

Symptom: Emails sent but in spam folder

Solution:

  1. Check spam folder thoroughly
  2. Add to safe senders list
  3. Configure SPF/DKIM records in iPage DNS
  4. Use authenticated sender email

Issue 4: iPage Requires SMTP Instead of mail()

Symptom: mail() doesn't work on iPage

Solution: Switch to SMTP (see instructions below)

🔍 Check Email Logs

After submitting a test or real application, check the following log files:

  • logs/email-attempts.log - All email send attempts
  • logs/email-errors.log - Failed email attempts
  • logs/ambassador-submissions.log - Successful submissions
  • logs/email-test.log - Test email results

Note: You'll need FTP or cPanel File Manager access to view these logs
