## The Central Truth

Conflict is inevitable; **mastery is optional**.  
Martial arts train skill under attack — not the absence of opponents. Relational mastery installs a protocol: pause, own, repair — so reaction does not become your only teacher.

---

## Week Overview

### Core Question
What protocol turns inevitable conflict into governed skill?

### Key Insight
Your top conflict errors are usually few and repetitive. Name two, write a household protocol, and run it in two real situations this week.

### Learning Outcomes
- Identify top two conflict errors  
- Create a written conflict protocol  
- Practice pause–own–repair  
- Apply protocol in two real situations  
- Pass a Conflict Mastery Audit  

---

## Core Teaching

### 1) Top errors (pick two)

Examples: contempt openers; bringing archives; blocking exits without return; refusing to own 10%; winning the point; volume; sarcasm; recruiting allies mid-fight.

### 2) Conflict protocol (household card)

1. **Cue** — raised voice / shutdown / contempt word  
2. **Pause** — X minutes; who says the code word  
3. **Return** — exact time  
4. **Own** — each names their 10%+ without counterattack first  
5. **Mirror** — one paraphrase each (Week 4)  
6. **Ask** — one request each  
7. **Repair** — next act + time  
8. **If stuck** — table to governance meeting (Course 09 W6)  

### 3) Pause — own — repair

- Pause without abandonment  
- Own without fog  
- Repair without bribery gifts that skip ownership  

### 4) Two real situations

Log both: cue, protocol steps used, where you cheated, outcome at 24h.

### 5) Analogy: martial arts

White belt flails. Black belt uses form under adrenaline. Form is love’s technique.

### 6) Power check (Course 09 W3)

Protocol fails if the powerful party skips it. Mastery includes submitting your power to the card.

### 7) Continuity

Protocol creates ruptures that need forgiveness structure (Week 6) — not only techniques.
