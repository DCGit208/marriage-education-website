How to use Canon AI
  1. Open a week part in the editor.
  2. Optionally select the paragraph to improve.
  3. Add an instruction (or pick a prompt idea).
  4. Use Draft, Expand, Rewrite, Align canon, or Outline.
  5. Review, Save draft, then Publish.

If you see a 429/rate-limit message, wait — Studio auto-retries. Avoid clicking multiple actions at once.

Draft only — review & Publish yourself.

    2. Approve — “Looks good” (still draft for learners)
