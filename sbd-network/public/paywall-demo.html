🔒 Paywall Modal System

Interactive demo of the paywall modal component with tier comparison.

1. Basic Usage

Trigger the paywall modal with a simple function call:

// JavaScript
function showPaywallDemo() {
  showPaywallModal({
    title: 'Upgrade Required',
    message: 'This content requires a premium subscription.',
    requiredTier: 'premium'
  });
}

4. Page Integration Guide

Step 1: Include CSS & JS

<!-- In your HTML <head> -->
<link rel="stylesheet" href="/css/paywall.css">
<script src="/js/formation-access.js"></script>

Step 2: Check Access

// In your page's JavaScript
async function checkContentAccess() {
  const userId = auth.currentUser?.uid;
  const canAccess = await canAccessModule(userId, 'module-id');
  
  if (!canAccess) {
    showPaywallModal({
      title: 'Premium Content',
      message: 'This module requires Premium access.',
      requiredTier: 'premium'
    });
    return false;
  }
  
  return true;
}

Step 3: Handle Module Load

// module.js example
document.addEventListener('DOMContentLoaded', async () => {
  const hasAccess = await checkContentAccess();
  
  if (hasAccess) {
    loadModuleContent();
  } else {
    // Content remains locked, paywall shown
  }
});

5. Customization Options

Available Parameters:

  • title - Modal title (default: "Upgrade Required")
  • message - Descriptive text (default: generic message)
  • requiredTier - Minimum tier needed: 'foundation', 'premium', or 'elite'
  • currentTier - User's current tier (optional, for comparison)

Example with All Options:

showPaywallModal({
  title: '🎓 Sexual Literacy Awaits',
  message: 'Complete understanding requires Premium access. Join 500+ couples transforming their marriages.',
  requiredTier: 'premium',
  currentTier: 'foundation'
});

Note: When users click a tier button, they're redirected to /checkout.html?product={productId}
