## 🎯 PROGRAM OVERVIEW

**Program Name**: Marriage Foundation School

- Practical conflict resolution transformation

**Daily Practice Installation** (25 min/day × 7 days)

**Required Readings**
- SBD for Dummies: Chapter 1 (pp. 15-42) + Chapter 9 (pp. 127-158)
- Scripture: Genesis 1:27; 2:24-25, Matthew 5:48, Hebrews 5:14, Luke 16:10, Ephesians 4:13

### **WEEK 2: DESIGN PARADIGM + SALES & COMMUNICATION** (15 hours)

#### **PART A: TELEIOS BLUEPRINT - Design Paradigm: Thinking from First Principles** (8 hours)
*Source: Existing course content - Week 2*

**Core Teaching** (65 min)
- Design vs. Damage: Blueprint vs. Cultural Distortion
- The 4 Elements of Design: Intent, Blueprint, Load-bearing requirements, Consequences
- Design vs. Preference: Non-negotiable vs. Flexible
- The Design Lens Framework: 3 questions to diagnose any issue
- Repair vs. Rebuild: Surface vs. Structural problems

**Interactive Exercise: Build Your Design Dictionary** (120 min)
- Define 10 core terms WITH your partner: Covenant, One-flesh, Fidelity, Nakedness, Desire, Authority, Submission, Leadership, Peace, Repair
- Compare definitions, discuss differences, build shared meaning
- Address cultural vs. biblical definitions

**Case Study: The Smith Family Rebuild** (45 min)
- 8-year marriage, pornography addiction, near divorce
- Therapeutic approach (failed for 2 years) vs. Design approach (breakthrough in 12 months)
- Identity work: "Who am I apart from addiction?"
- Rebuild from design principles

**Design Lens Application** (60 min)
- Apply 3-question framework to ONE recurring conflict
- Q1: What does design say?
- Q2: What's the current deviation?
- Q3: What's the smallest structural action today?

**Required Readings**
- SBD for Dummies: Chapter 1 (pp. 15-22), Chapter 5 (pp. 43-58)
- Scripture: Genesis 1:27; 2:24, Isaiah 1:18, Ephesians 4:26, Ephesians 5:22-33, 1 Corinthians 7:3-5

**Assignments**
- Design Dictionary (10 terms, all 3 formats: IS/NOT/Looks like) - 750-1000 words
- Design Lens Analysis (one conflict)
- Repair or Rebuild diagnosis with evidence
- Discussion forum participation


**Generation Process:**
1. **Trigger**: When all requirements met
2. **Generate**: Create PDF using jsPDF library
3. **Store**: Upload to Firebase Storage
4. **Record**: Save certificate data in Firestore
5. **Notify**: Send email with download link
6. **Display**: Show in ambassador dashboard

**Firebase Function:**
```javascript
exports.generateCertificate = functions.https.onCall(async (data, context) => {
  const { ambassadorCode } = data;
  
  // Verify completion
  const enrollment = await checkCompletion(ambassadorCode);
  if (!enrollment.allRequirementsMet) {
    throw new Error('Requirements not met');
  }
  
  // Generate certificate number
  const certNumber = await generateCertNumber();
  
  // Create PDF
  const pdfBuffer = await createCertificatePDF({
    name: enrollment.ambassadorName,
    certNumber: certNumber,
    completionDate: new Date(),
    hours: enrollment.totalHoursSpent
  });
  
  // Upload to Storage
  const fileUrl = await uploadToStorage(pdfBuffer, certNumber);
  
  // Save record
  await db.collection('certificates').doc(certNumber).set({
    ambassadorCode,
    ambassadorName: enrollment.ambassadorName,
    certNumber,
    issuedDate: admin.firestore.FieldValue.serverTimestamp(),
    pdfUrl: fileUrl,
    status: 'active'
  });
  
  // Update enrollment
  await db.collection('school_enrollments').doc(ambassadorCode).update({
    certificateIssued: true,
    certificateNumber: certNumber,
    completionDate: admin.firestore.FieldValue.serverTimestamp()
  });
  
  // Send email
  await sendCertificateEmail(enrollment.email, fileUrl);
  
  return { success: true, certNumber, downloadUrl: fileUrl };
});
```
