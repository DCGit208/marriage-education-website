📌 Purpose of This Framework

Week 3 Core Teaching: You inherit sexuality as birthright (anthropogenic design). Stewardship requires sorting pleasure into ALIGNED (with design) vs MISALIGNED (against design) categories.

Key Principle: Literacy precedes morality (Hosea 4:6). You cannot properly assess sexual behavior without understanding design first.

📖 Key Theological Terms (Dake Study Bible Definitions)

Porneia (πορνεία, G4202):

Definition: Fornication, all manner of unlawful sexual relations (adultery, incest, sodomy, harlotry, idolatry).

Scope: Umbrella term for ALL misaligned stewardship.

Key Verse: Matthew 5:32—"Saving for the cause of fornication..."

Moicheia (μοιχεία, G3430):

Definition: Adultery, specifically unlawful sexual relations between men/women (married or single).

Relationship: All adultery is porneia, but not all porneia is adultery (e.g., sodomy is porneia but not adultery).

Teleios (τέλειος, G5046):

Definition: Complete, mature, full-grown, perfect (not morally perfect, but developmentally complete).

Application: "Full age" = legal age + teleios maturity (4 attributes fully developed).
