## 💰 COMMISSION STRUCTURE

### **Standard Rate: 10% Advocacy Earnings**

**Ambassador (Regular):**
- Earns: **10%** on all access they deploy directly
- Example: Deploy Foundation School (1,200,000) → Earn 120,000 FCFA

**Senior Ambassador:**
- Personal Deployment: **10%** on their own deployments
- Team Override: **5%** on their 10 ambassadors' deployments
- Example: Team member deploys school (1,200,000) → Senior earns 60,000 FCFA override

**Regional Director:**
- Direct Deployment: **10%** on their own deployments (if any)
- Team Override: **5%** on entire network (50 seniors + 500 ambassadors)
- Example: Network member deploys school (1,200,000) → RD earns 60,000 FCFA override

```javascript
// Cloud Function triggered on ANY sale
exports.processProductSale = functions.firestore
  .document('sales/{saleId}')
  .onCreate(async (snap) => {
    const sale = snap.data();
    
    // Get product details
    const product = await getProduct(sale.product_id);
    
    // Get customer source attribution
    const customer = await getCustomerSource(sale.customer_email);
    
    // Calculate commissions
    const commissions = {
      ambassador: sale.amount * 0.10,
      senior: customer.source_senior ? sale.amount * 0.05 : 0,
      rd: customer.source_rd ? sale.amount * 0.05 : 0
    };
    
    // Update all three levels
    await updateAmbassadorEarnings(customer.source_ambassador, commissions.ambassador, product);
    if (customer.source_senior) {
      await updateSeniorOverride(customer.source_senior, commissions.senior, product);
    }
    if (customer.source_rd) {
      await updateRDOverride(customer.source_rd, commissions.rd, product);
    }
    
    // Send notifications
    await notifyEarnings(customer.source_ambassador, commissions.ambassador, product.name);
  });
```
