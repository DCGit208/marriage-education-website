Frequently asked questions

Quick answers

I am already an operator. Where do I log in?

Choose your role in the operator access section above. The links lead to the existing Ambassador, Senior Ambassador, Regional Director, and Executive Network Director login pages.

Which operator role should I choose?

Select the role for your existing operator account. If you are new, explore the Ambassador registration or Regional Director application pathway below.

How does the Ambassador pathway differ from leadership roles?

Ambassadors deploy approved educational resources. Senior Ambassadors support and develop Ambassador teams, while Regional Directors coordinate regional leadership. The Executive Network Director provides broader network leadership.

Where can I apply to become an Ambassador?

Use the existing Ambassador registration page.

Where can I apply for Regional Director consideration?

Use the existing Regional Director application page.

What is Marriage Foundation Access?

It is an educational-access offering separate from operator registration. Explore the Foundation Access page.

Does this page replace my dashboard?

No. This is a public entry point that helps you find an existing role-specific login or pathway. It does not replace or change operator dashboards.
