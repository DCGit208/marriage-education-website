Deployment Operations — Navigation Guide

Sitemap and walkthrough for your DOS dashboard. Replay the interactive tour anytime with Guide in the top bar.

First time? Use the Guide button on your dashboard for a step-by-step highlight tour. This page is the full reference you can bookmark or print.

Every role — common sections

  1. Overview — Daily snapshot: KPIs, monthly target, quick actions, path to Senior (10 recruits).
  2. Daily ops — Log outreach and deployment activity for the day.
  3. Field deploy — Conversation scripts for approach, close, follow-up, objections.
  4. Deployment links — Your referral URL, product links, SBD app panel, social share.
  5. Subscribers & pipeline — Prospects and subscribers by stage; recent deployments.
  6. Retention — At-risk subscribers and follow-up focus.
  7. Commissions — History, recurring view, portfolio earnings by category.
  8. Social deploy — Caption library for WhatsApp, Facebook, Instagram.
  9. Reports — Export summaries for your records.
  10. Network — Ambassadors you recruited.
  11. Formation — Foundation School / CRLA (training is separate from deployment ops).
  12. Performance — Leaderboard, contests, revenue stacks, unit milestones.

Senior — Team command

  1. Team command — Downline ambassadors, team activity, who needs support.

Regional Director — Regional command

  1. Regional command — Territory metrics, seniors in region, inactive alerts.

Executive — Global command

  1. Global command — Network-wide aggregates and executive KPIs.

Top bar shortcuts

  • Guide — Replay the interactive walkthrough.
  • Map — Opens this navigation guide.
  • Copy main link — Your primary campaign referral URL.
  • Announcements — Bell icon for admin messages.
  • Logout — Returns you to your role login page.

Suggested daily flow

  1. Open Overview — check KPIs and target.
  2. Complete Daily ops — log today’s outreach.
  3. Use Field deploy scripts in conversations.
  4. Share from Deployment links or Social deploy.
  5. Update Subscribers / Retention after contacts.
  6. Review Commissions when sales post.
  7. Leaders: check Team / Regional / Global as applicable.
